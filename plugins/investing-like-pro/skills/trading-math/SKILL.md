# trading-math — 交易的「贏家數學」評估器

## 這是什麼

一套把「一個交易系統會不會賺、能不能活到 edge 兌現」**量化成數字**的框架,出自交易數學的四個核心概念。核心信念:**單筆交易約等於擲硬幣(50/50),長期成敗由「系統的數學」決定**,不是任何一筆的輸贏、不是完美進場點。多數人把力氣全砸在策略/指標/心理,卻不看那個唯一能告訴你「會不會賺」的數字——期望值。

> ⚠️ **非投資建議**:本 skill 僅做機率與風險的數學計算與觀念說明,**不提供任何買賣訊號、不預測行情**。所有交易風險由使用者自負;數字例子僅為示範,實際以使用者自己的系統統計為準。

## 什麼時候用(觸發情境)

- 使用者報出系統統計(勝率、賠率 R 或平均賺/賠、每筆風險 %、帳戶餘額、停損點數),問「行不行 / 該下多少 / 破產機率」。
- 使用者連虧後想加碼、或問「下一筆是不是該中了」→ 用**賭徒謬誤**糾正。
- 使用者問「虧 X% 要賺多少才回本」→ **復原數學**。
- 使用者想理解 expectancy / variance / risk of ruin / position sizing 等概念。

## 四個概念 + 公式(回答時照這個框架走)

### 1. 期望值 Expectancy —— 唯一真正重要的數字
```
期望值/筆 = 勝率 × 平均獲利 − 敗率 × 平均虧損 −(每筆成本)
```
- **為正 = 有一套會賺錢的系統**;為負,再多努力都是把錢倒進破洞。
- **反直覺**:勝率高低本身不重要。8R@15%(輸 85%)期望值 +0.35R;1R@70% 期望值 +0.4R——兩者差不多。**edge 在「勝率 × 賠率」的組合,不在任一個單獨數字。**
- **隱藏成本**:點差 spread、手續費 commission、滑價 slippage 會吃掉紙上期望值。**紙上獲利 ≠ 實盤獲利**,務必把成本算進去。
- **大樣本才算數**:前 10–20 筆全是雜訊,約 100 筆真相才浮現。**別用三五筆就判系統好壞**(很多人在 edge 顯現前就退場)。

### 2. 系統設計 System Design —— 接受沒有完美策略
- **trade-off**:賠率越高、勝率通常越低(目標放越遠,價格到得越少次,是市場本質、不是你做錯)。別找「高勝率又高賠率」的聖杯,不存在。
- **甜蜜點**在中間、且**你能在幾百筆裡穩定執行**的那個(如 40%@4R、50%@3–4R),而非回測最漂亮的。
- **損益兩平勝率**:`breakeven = 1 / (1 + R)`。1R 要 >50%、**4R 只要 >20%**(可以錯 80% 仍不虧)——拿這個替交易者鬆綁心理壓力。

### 3. 變異數 Variance —— 為什麼情緒上崩潰
- **同一套系統、同樣期望值**,權益曲線可以天差地遠(平滑向上 / 慘烈回撤 / 中間)。**你可以每件事都做對還是連虧 7 筆;也可以違反每條規則連贏 5 筆(更危險)。**
- **短期結果證明不了任何事,只有大樣本說真話。**
- **賭徒謬誤 Gambler's Fallacy**:每筆獨立。連虧 5 筆後,下一筆**還是 50/50**,不會變 82%/91%。→ **連虧時絕不加碼**(這是最常見的爆倉原因)。

### 4. 風險 Risk —— 活得夠久 edge 才有機會兌現
- **部位大小**:固定「每筆冒的錢」(帳戶 0.25%–2% 為上限),不是固定手數。停損越寬 → 部位越小。`部位 = (餘額 × 風險%) / (停損距離 × 每單位每點價值)`。
- **破產風險 Risk of Ruin 隨風險% 爆炸**:在邊際系統上,每筆冒 0.5%→近 0、1%→約 7%、2%→約 61%、5%→近乎必死(出現大回撤的機率)。「連虧不是問題,你的部位大小才是。」
- **復原不對稱**:`回本報酬 = d / (1−d)`。虧 10% 要賺 11%、虧 30% 要 43%、**虧 50% 要 100%(翻倍)**。所以保住本金最重要。

## 那一個問題(收尾一定要問)

> **「有哪一件你心知肚明做錯、只要修正就能徹底改變交易的事?」**

常見答案(幫使用者對號入座):只憑幾筆就判系統 / 冒太大險只為「感覺到什麼」/ 把好結果誤當好執行 / 一遇回撤就拋棄 edge / 在機率遊戲裡追求確定性。不論答案是什麼,**該做的都一樣**:想機率不想結果、用大樣本評斷 edge、冒夠小的險熬過變異數、一致性勝過完美、**你的工作是執行不是預測**。

## 怎麼用這個 skill(操作流程)

1. **問齊數字**:勝率、賠率 R(或平均賺/賠金額)、每筆風險 %、帳戶餘額、停損距離(算部位時)、每筆成本(可選)。
2. **跑腳本算**,別只用嘴估(`scripts/trading_math.py`,純標準函式庫、無相依):
   ```bash
   # 綜合體檢(一次跑完四個概念)
   python scripts/trading_math.py report --winrate 0.45 --r 2 --risk-pct 0.02 --balance 10000

   # 單項
   python scripts/trading_math.py expectancy --winrate 0.15 --r 8        # 或 --avg-win 1200 --avg-loss 1000 --costs 5
   python scripts/trading_math.py breakeven --r 4
   python scripts/trading_math.py recovery --drawdown 0.5
   python scripts/trading_math.py position --balance 1000 --risk-pct 0.005 --stop 25 --pip-value 0.1
   python scripts/trading_math.py ruin --winrate 0.40 --r 1.5 --risk-pct 0.02 --threshold 0.3
   ```
   也可 `import trading_math` 當模組用:`expectancy()`, `breakeven_winrate()`, `recovery_pct()`, `position_size()`, `risk_of_ruin()`。
3. **下判斷**:期望值為正且為負分別代表什麼;勝率有沒有過 breakeven;在不同風險% 下破產機率如何變化;若發生 50% 回撤要賺多少回本。**把破產風險用「0.5/1/2/5% 並排比較」呈現,讓使用者看到爆炸式上升。**
4. **收尾丟出「那一個問題」**,並提醒非投資建議。

## 注意

- `ruin` 是 Monte Carlo(預設 20000 次模擬),用「固定百分比風險複利」模型;**正期望值 + 小風險的系統很少觸及 50% 回撤**(這本身就是好消息:edge + 控險 = 生存)。要看到破產機率明顯上升,通常發生在期望值接近 0 或風險% 偏大時。
- 所有金額/點值單位由使用者定義(外匯 pip、股票 tick、點數皆可),`value_per_unit` 代表「每 1 單位部位、每 1 停損距離」的金額。
- 這是**機率框架**,不是預測工具;它告訴你「這套系統的數學長相」,不告訴你「下一筆會不會贏」。
