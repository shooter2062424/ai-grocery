# 股癌投資思維框架 —— 用「他的腦袋」評斷一支股票好不好

> 這是本 skill 的 **核心大腦**。它不是「股癌最近推薦什麼」的清單，而是從 EP1–EP665 全部逐字稿
> 萃取出來的 **評斷準則**：拿一支股票進來，用他重視的維度、指標與決策規則去判斷它「好不好、值不值得、
> 風險在哪、該怎麼操作」。**他近期看好的標的只當「輕度輔助」**（見最後一節），不是判斷的主軸。
>
> ⚠️ 這是對一位真實公開人物方法論的 **模擬與推斷**，非謝孟恭本人意見、非投資建議。

---

## 評斷流程總覽

```
1. 先「分型」這支股票 → 決定要套哪一套規則（成長/題材/循環/防守/平台壟斷）
2. 跑七大維度評分（用 fetch_indicators.py 撈指標，必要時動態改寫腳本撈更多）
3. 過一遍「紅旗」清單（出現紅旗大幅扣分）
4. 疊加「輕度輔助」：他近期立場/排名（±一點點，不主導）
5. 產出 verdict：好 / 普通 / 避開 + 理由 + 風險 + 操作建議 + 免責
```

---

## 第一步：先給股票「分型」（規則會分流）

股癌不會用同一把尺量所有股票。**先判斷它屬於哪一型**，因為每一型最重要的指標不同：

| 類型 | 特徵 | 評斷重心 | 估值方式 |
|---|---|---|---|
| **成長股** | EPS/營收高速成長、未來故事清楚 | forward EPS 成長率、營收 YoY、能見度 | PEG、forward PE，成長高可給高倍數 |
| **題材股** | 靠某個族群題材（AI、衛星、被動元件…） | **營收佔比 / 題材純度**、放量時間軸 | 先給想像倍數、再看 EPS 跟不跟得上 |
| **景氣循環股** | 報價/供需驅動（記憶體、被動元件、航運、面板） | 稼動率、報價、成本 vs 需求驅動 | **不能用 PE 看**；高檔低 PE 是陷阱 |
| **價值/防守股** | 低成長但便宜、殖利率穩 | forward PE、殖利率、現金流 | forward PE ~10 倍「很難輸」(EP661) |
| **平台/壟斷股** | 護城河深、客戶綁定（軟體、龍頭平台） | 護城河、議價權、續約/綁定 | 容忍高估值，看的是不可取代性 |

> 一支股票可同時帶多型（例：台積電＝成長＋平台壟斷）。分型是為了「知道哪個指標最該看」，不是貼標籤。

## 第二步：七大評斷維度

每個維度列出 **他在看什麼指標、決策規則、EP 佐證、會扣分的紅旗**。

### A. 估值（他真正的算法，不是看 PE 高低）

**他怎麼算：** 核心是 `合理股價 ≈ forward EPS × 合理本益比倍數`。倍數由「成長性 × 同業 × 產業 × 市場情緒」共同決定。

- **用 forward EPS，不要用過去幾季 EPS 算 PE 喊貴**（EP636 點名這是常見錯誤）。
- **同樣 EPS，用 PEG 比高下**：成長率高的本來就該有更高估值（EP637：一家 EPS 5→10、一家 9→10，差很多）。
- **產業有「乘數天花板」**：IC 設計 / IP / 軟體給高倍（30–50x）；塑化、面板、純代工給低倍（~20x 封頂，EP650）；**景氣循環股不能用 PE**。
- **實戰估值法（EP665 國巨示範）**：用上一輪循環高點的毛利率（2018 國巨毛利摸 60%）類比 → 推算明年可能 EPS → 套倍數 → 得出 target price。**這就是他親手示範的算法，照做。**
- **「防守線」概念**：心中隨時有一份 forward PE ~10 倍的清單，「10 倍的東西很難輸」(EP661)。市場恐慌時這些是底氣。
- **高估值能撐很久**：只要一直有新利多上修（EP646）；別只因「PE 看起來高」就喊賣。
- **便宜的 catalyst**：相對便宜的標的要有「新變化/催化劑」才會吸引資金進場（EP656 台積電在 AI Peer 裡相對便宜）。

🚩 **紅旗**：用 2028/2029 年的 EPS 來合理化「現在」的 50 倍 PE（EP660）；只會喊「恨天高目標價」卻講不出倍數依據（EP661 小作文特徵）；「便宜」但無成長、無催化 → 價值陷阱（EP659）。

### B. 成長與基本面（EPS 成長是根本）

**指標：** EPS 成長、營收 YoY、毛利率、營益率、能見度/在手訂單、稼動率。

- **EPS 持續成長 → 股價持續成長**，這是他鼓勵研究 Fundamental 的根本（EP624）。
- **毛利率 = 競爭力**（EP19/38 高毛利象徵高競爭力）。但 **要辨別毛利率下降的原因**：
  - 結構性、健康的下降：Buy and Sell / 整機代工模式，毛利率↓但賺的「絕對金額」↑（EP618/633 緯創 vs 鴻海、L6 打板）。→ 不該扣分。
  - 真正轉差：競爭、削價、成本轉嫁不出去（EP631 網通毛利被記憶體漲價吃掉但能轉嫁就還好）。→ 扣分。
- **能見度 / 在手訂單**：缺貨能見度到 2027、訂單滿（EP658）= 加分。
- **稼動率 / 產能利用率**：循環股最準的領先指標（EP654）；稼動率墊高到臨界點會「瞬間滿載→漲價」(EP628/660)，從 8%→10% 那 2% 會被秒殺。
- **挑指標看產業**：ROE 對銀行股不準（負債比高，EP29）；要懂指標在衡量什麼。

🚩 **紅旗**：營收很漂亮但換算 EPS 很普通（EP653 用 GP 看很恐怖、換 EPS 收斂）；毛利率下滑且轉嫁不出去；稼動率已滿載（漲價題材的後段，續航力存疑）。

### C. 題材純度與營收佔比（看題材時「最常強調的重點」）

- **營收佔比要夠高**：題材要能帶動股價，受惠部分得佔營收夠大，「或者現在只有 5%，但三年內會變 30%」才可以看（EP640 原話）。佔比拉不上來，就不會被題材輪動帶上去。
- **純度**：純度不夠、題材太廣、咬到的營收佔比低 → 市場不愛（EP641 多次用「夠不夠純」篩選衛星/光通股）。
- **驗證方式**：去查 BOM 佔比、地區營收佔比（EP630 昇達科衛星佔比近 70%＝第一棒合理；EP640 看地區佔比就知道誰真受惠）。

🚩 **紅旗**：只有「沾邊」題材、營收佔比個位數又三年內拉不起來（EP632/655 BMC 佔比不高還硬炒）；通路/代理硬要當受惠股（EP624）。

### D. 競爭力 / 護城河

- **龍頭優先**：選股先看族群龍頭（EP36/596/624）。非龍頭只因「比較便宜、還趴在地上」就買 → 通常有原因（EP613）。
- **贏者全拿**：產業遇逆風時，份額會集中到競爭力強者，不是大家一起均分（EP5/6）。
- **護城河類型**：客戶綁定/轉換成本/壟斷（EP569 軟體客戶綁死、EP636 Palantir「只有他一家」）、議價權/採購規模（Apple 大客戶議價、EP659 五哥十哥議價弱毛利低但能確保賺錢）。
- **對「誰取代誰」要懷疑**：「千萬不要隨便相信誰取代誰，尤其中間解方不易被取代」(EP635/639 SRAM/DRAM 取代 HBM 的假說)。AI 取代論多半是雜訊（EP644 SaaS-pocalypse、EP658 反擊取代論）。

🚩 **紅旗**：護城河靠補貼/價格戰堆出來（EP593 補貼殺到內捲）；產品競爭力弱、導入 AI 後對手反而更多（EP633）。

### E. 預期差 / 錯殺（市場錯誤定價）

- **利多不漲 = 警訊**：財報利多但股價沒漲，常是典範轉移/見頂（EP641 NVIDIA 財報沒漲、EP646 美光毛利 70%+ 卻沒大漲）。
- **利空不跌 = 強勢**：講完壞消息市場不跌，視為一次「過度反應已被消化」(EP565)。
- **price in**：已知訊息都會反映在股價，而且常 **過度** 樂觀或悲觀（EP28）。要問「現在基本面反映了沒？」(EP640)。
- **真錯殺 vs 殺到位**：被「無條件殺下來、但成長其實很強勁」＝真錯殺，第一順位撿（EP637 Cloudflare）；只是「沒有這麼差吧」的，可能就此被淘汰，別接。錯殺要有 **財務數字佐證**，且通常 **很快站回去**（真金不怕火煉，EP648）。
- **領先指標**：台股每月營收、市場走勢本身就是領先指標（EP32/623）。
- **擁擠交易**：市場超有共識、資金都擠進去的撐盤對象，等別的反彈就輪到它被殺（EP637）。

🚩 **紅旗**：把下跌一律當「錯殺」抄底（EP2 他不愛「錯殺」這詞，提醒那常是事後論）；逆勢放空有共識的強勢股（EP33「可以做多可以空手，千萬不要放空」）。

### F. 景氣循環股紀律（循環股專用）

- **股價領先報價**：循環股股價走在現貨報價前面；等財報/報價確認時常已在高檔。
- **成本驅動 vs 需求驅動的漲價要分清**（EP661）：需求驅動較健康；純成本驅動，除非廠商有上游自給（如做鋁電容又自有鋁箔子公司）才有優勢。
- **高檔 + 業者說詞囂張 → 警惕**（EP630/646 記憶體 supercycle 的教訓，他自己曾被洗掉五成部位 EP608）。
- **擴產共識 = 好景不長訊號**：大家都喊擴產，代表供需缺口會被解決，「不會維持超高毛利很久」(EP663)。
- **別小看 Legacy/低階料**：缺貨後段，低階反而漲贏高階（EP661/664 DDR4/DDR5 毛利跑贏 HBM）。

🚩 **紅旗**：在循環高檔用「低 PE」說它便宜（循環股低 PE 常是賣點不是買點）；報價已飆、稼動率滿載、人人喊擴產時才追進去。

### G. 風控 / 部位 / 節奏（買不買得起、扛不扛得住）

- **控水位、留子彈**：留 15–20% 現金，看 Sharpe ratio 與資金維持率，不被別人月報酬破百影響（EP643/655）。槓桿別太高，隨時可能被殺（EP641）。
- **分散小部位反而吃得到完整波段**：佔比不高的部位，跌時懶得動、扛過回檔，最後吃到整段（EP662）。
- **停損紀律**：停損佔比太大時心態會跑掉、機械化操作會失準（EP659）。
- **時間軸意識**：題材的「放量時點」很重要（玻璃基板放量在 2027–2028，別被情緒帶著提前炒，EP648）。
- **不追高、回檔買強勢**：回檔是強勢多頭的買點（EP654），但不無腦追高（EP661/663）；汰弱留強。
- **見招拆招**：不預設單一劇本；盤面轉弱就從「追強」改成「找被錯殺的」(EP609)。

🚩 **紅旗**：要靠融資/槓桿才買得起；買進理由說不清楚、只會編「殖利率不錯、法人按讚」等 BCD 理由賭價差（EP644）。

## 第三步：產出 verdict（評斷模板）

把七維度收斂成一句結論。建議格式：

```
【股癌框架評斷：<股票>】
分型：<成長/題材/循環/防守/平台壟斷（可複合）>
估值：<forward PE / PEG / 產業乘數天花板對照，目前偏貴/合理/便宜，附他的算法>
基本面：<EPS 成長、毛利率與其結構、營收 YoY、稼動率/能見度>
題材純度：<營收佔比夠不夠高、純不純>
護城河：<龍頭？綁定/議價權？取代風險？>
預期差：<有沒有利多不漲/錯殺/擁擠交易訊號>
（循環股才加）循環位置：<報價/稼動率/成本 vs 需求/擴產共識>
風控：<估值防守線、該用多少水位、時間軸>
紅旗：<列出觸發的紅旗>
─────────────
模擬結論：好 / 普通 / 避開（給理由，用他的口吻：直白、講風險、不打包票）
他可能的操作：<族群怎麼配、水位多少、回檔分批還是現在追、時間軸>
⚠️ 免責：本評斷為對股癌方法論的模擬推斷，非謝孟恭本人意見，非投資建議。
```

**口吻**：直白、帶點靠北幽默、會自嘲、一定會講風險、不打包票（「這東西看起來不錯，但你要知道你在買什麼」）。

## 第四步：「輕度輔助」層——他近期立場只是加減分，不主導

> **這是這次改版的關鍵：不要用「他最近有沒有推薦這支」來決定股票好不好。**
> 好不好，**先用上面七維度框架算出來**；他近期立場只在最後 **微調信心**：

- 讀 `recent-stance.md` / `recency-ranking.md`：
  - 若框架判定「好」**且** 他近期也偏多 → 信心 ↑（但理由仍以框架為準）。
  - 若框架判定「好」**但** 他近期沒提或轉謹慎 → 照框架走，註明「他近期較少著墨/轉謹慎」。
  - 若他近期「推薦」某標的 → 當成「一個值得用框架檢驗的候選」，**不是**「因為他推薦所以是好股」。
- **提及頻率 ≠ 看多**：排名只是「他最近常談什麼」的頻率訊號，可能是唱衰/對照組（`recency-ranking.md` 已標註）。
- 他自己就反覆強調：**不要因為某人推薦就買，要自己知道在買什麼**（EP644 別編 BCD 理由賭價差）。

## 紅旗總表（出現任一，結論要保守）

1. 用未來 2–3 年的 EPS 合理化「現在」的高 PE。
2. 只有恨天高目標價、講不出倍數依據（小作文）。
3. 便宜但無成長、無催化 → 價值陷阱。
4. 營收很大但換算 EPS 普通；毛利率轉差又轉嫁不出去。
5. 題材純度低、營收佔比個位數且三年拉不起來、純沾邊。
6. 非龍頭只因「便宜、還在地上」而買。
7. 護城河靠補貼/價格戰；產品力弱導入 AI 後對手更多。
8. 把所有下跌都當錯殺抄底；放空有共識的強勢股。
9. 循環高檔用低 PE 說便宜；報價飆、稼動率滿、人人擴產才追。
10. 要靠槓桿才買得起；買進理由只剩 BCD 理由。
