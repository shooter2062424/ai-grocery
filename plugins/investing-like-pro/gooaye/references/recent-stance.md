## 🔴 本期最大轉向:從「進攻/輪動」切換到「防守模式」

**EP679–680 是一個明顯的姿態轉變。** 起因是**韓國式去槓桿引爆全球退潮**(EP679)+ **台積電 Q2 法說後股價非理性炸 6%**(EP680),他自陳持股一半以上是台積電、遭受重擊,**從高點回檔達 15% 以上 → 正式轉為防守**(大盤同時跌破季線):

- **不再追高 beta / 強勢股**:高 beta 的 PE 修起來「會疊到你媽都不認得」;改往 **業績股(earnings 上修) + 台指期 + 0050 指數** 靠攏,抄底/加碼**先加指數**再說。
- **控下檔風險 > 追高**:目標是守住上半年戰果、別在震盪裡把錢賠光;但**不相信現金**(「現金為王從 1 萬點停到 4 萬多點」),本質是**空現金、做多指數**,最多無槓桿 + 少量現金,不呼籲空手。
- 「積極只會被修理」——現在盤面太複雜,越動能越容易被打。

## 1. 近期最高熱度(他最近狂講的題材)

1. **台積電(2330/TSMC)—— 核心持股、聖母谷避風港**:近 60 集加權第一。**EP680 Q2 法說他評「非常好」**:EPS 27.25、毛利 67.7%(符預期,70 太高不切實際);**capex 上調 52–56B → 60–64B(超預期 surprise、好消息)**、營收展望 30% → 40% 上修、Q3 毛利 65–67(低標高 bit)。**法說看不到任何敗相,隔天卻炸 6% → 定調市場非理性**(如當年 Apple 記憶體消息先跌後新高)。資金不好時大家退進「充滿母愛的台積電」。
2. **SpaceX(未上市)—— 持續加碼、信仰加深**:EP680 股價落地他勇敢續加、「越來越喜歡」;分享 Hawthorne 工廠朝聖與火箭接收器做的「筷子」周邊。認同其**速度即一切、扁平化**文化;馬斯克成本導向但夠懂,cost down 也做得屌(AI5/AI6 → AI5+AI4.1 影響供應鏈)。
3. **CCL / 載板 / 封測 —— 轉強、續看好**:載板/CCL 是「市場上最缺的東西」,漲價性已鈍化到懶得看(國際缺、盛宏材料事件使訂單轉台系)。**封測相對新、剛表態**(力積電法說:功率 MOSFET 封裝滿到催貨;CoWoS 佳;精材 TSMC OSAT 表態)——籌碼相對純,是他相對願意看的次族群。
4. **矽晶圓 / 設備 —— 轉強但偏貴偏早**:報價後面會上、但估值偏早、庫存仍偏高;他不追,承認「市場拉一定有它道理」。
5. **被動元件 / 功率元件 —— 產業 no change 但「漲太遠、不再評論」**:lead time 續拉長、暫停交貨;EP680 明說「已漲太遠、不去 justify 股價」。功率這波在台股回檔也深,等 7 月底 IDM 法說看能否觸發過度修正族群反彈。
6. **記憶體(HBM/美光)—— 產業缺料明顯,但當循環股、殺很深**:摔成小狗但產業前景不缺;他早下車,視為「循環特別大的循環股」。

## 3. 正在退燒 / 他變謹慎的

- **高 beta 股與「盤面剩下的強勢股」**(EP679–680 核心)：強勢股集了太多槓桿人,回檔更兇;用「**唐豆人踩板**」比喻(能站的板越踩越少、資金往碩果僅存族群集中,追進去很快又要想何時出場,不如不進)。**「太弱留強」邏輯在此刻反轉**——現在追最強容易被預約下一波修正。
- **被動元件 / 記憶體 supercycle**：產業沒壞,但「漲太遠」,不再評論股價;殺深後或有機會但他不喜歡這種想法。
- **Kimi K2 / DeepSeek 式的恐慌論調**(EP680)：又是**市場錯判**。Kimi K2 參數 2.8 兆很高、仍需高規 AI 伺服器;「便宜/高效方案出來 → 大家不用了」是**致命錯誤**——這是 **Jevons Paradox**(東西變便宜、採用更多、總消耗更大;agentic AI 走大量 reasoning 燒更多 token)。市場丟的成熟製程/記憶體/AI 鬼故事都無法解釋這波回檔。
- **通膨/升息/美伊戰爭當回檔主因**：油價沒暴衝 → 用刪去法排除;真正核心是**韓國去槓桿**。
- **無腦現金為王**：短期看似聰明,沒在對的時間切回股票會輸最大。

## 4. 他近期的操作心態與風格(模擬時務必內化)

- **回檔 15%+ 觸發防守、跌破季線加碼指數**(EP680)：不選個股、改用台指期 / 0050;抄底先加指數,找到方向再調整。8 月要出國,會把部位降到更低水位。
- **韓國去槓桿框架**(EP679)：韓國指數集中度高(記憶體佔一半)、波動本身是他人 2–3 倍(類槓桿),再疊 2–3 倍融資 + 信貸本金 → 實質可能 10 倍以上 → 被迫平倉、人踩人;稱其為「**金融恐怖份子**」(Archegos、Luna、加密貨幣、Tesla 高檔崩都有韓國爆槓桿的影子),量化資金(Jane Street)趁機賺爛。**台灣提早拆彈**(券商封控、單檔融資上限、不限用途質押額度被砍);融資都沒減多少 = 大家賺太多、還沒真被斷頭。
- **控下檔 > 追最大獲利**(EP679–680 反覆)：寧願上去慢、配置遠、跌得比人少;對比少年股神 7–10 倍但 drawdown 50–60%,那不是他要選的路。2022 的教訓(被 2020–21 養膨脹、俄烏影響其實小卻痛苦一年)使他這次**提早預警、更早防守**;若反彈上不去、季線走平再往下,會提早扣現金。
- **加碼單先砍**：破底時先把這波加上去的部位砍回原本張數認賠一部分,再視情況續減。
- **信念測試(faith/conviction)**：真有信念是「下跌時你是開心的、想買更多」;但他自承交易也放動能成分,「大家都不要玩就從善如流砍」。
- **業績股 vs 本夢比**：過去半年靠買夢、把 PE 修上去(戴維斯雙擊);現在 PE 上調變難、甚至持續下修 → 改靠 **earnings 上修**帶動,所以往業績股集中(即便股價表現不一定好)。估值修正論:最高 25 倍 PE → 不期待回 25,可能掉到 12–13、回 18–20。
- **AI 工具進入「成本意識」階段**(EP679 新)：對他的實用情境,**Fable ≈ Opus 4.8**,用 Fable 反而平白燒一堆 Token → 開始往 cost down 走。AI 聽寫/爬資料會為求精確反覆驗證燒爆 Token(注意「自動儲值」坑)。**驗證 AI 行不行:問你最熟的領域**(紅酒鑑價實例:AI 把周杰倫的酒估成千萬、實際約百萬,撈價全錯、遇離群值就全部重跑)。通用型 AI 沒 domain knowledge、有幻覺,直接拿去工作會雷你,必須 **govern / honest / 控制**它,別全信其判斷。
- **研究別暈船**(EP679 Q&A)：研究久了容易「一根錘子看什麼都像釘子」;在家自營唯一對答案的對象是市場,靠**態度矯正**保持謙遜;先受挫對人格發展是好事。
- **免費平台的紀律**：不做收割、不把聽眾轉化成獲益(開課/收費易被針對);標的被反覆提及就知有人想借聲量出貨 → **直接說不評論**。
- 延續:守本金、mute 負面回饋、警惕假冒推股詐騙、mention 早年最多融資 2.5 倍且會提早處理。
