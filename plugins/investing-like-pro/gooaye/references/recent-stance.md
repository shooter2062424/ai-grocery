## 3. 正在退燒 / 他變謹慎的

- **光通訊「narrow and fast」那側(矽光、化合物雷射)**(EP678 新):過去最香、現在線型軟掉,市場「瘋狂 sell 舊名字」;他類比「光進銅退」迷思——當年銅相關(Credo、Astera Labs、Amphenol)被殺爛,如今全在新高。**強調光銅是並行、不衝突**(in-rack 用銅、scale out/across 用光;narrow-and-fast 打較遠、wide-and-slow 用在 scale up/in),市場卻常做「把非純血的舊題材當狗殺」的白痴事。
- **Neo Cloud / 炒本夢比的算力供應鏈**(EP678 新):Meta 這種自用大買方也把算力丟出來出租 → 多一個有定價能力的超級玩家 → **算力單價會降(總價不一定,reasoning 燒更多 token)、價格趨穩 → 投報率算得出來 → 高估值收斂**。「朦朧美才最會噴」,價格一清楚,過去交易在 40–50 倍的東西要面對現實鐵拳。
- **記憶體 supercycle**:熱度在但收斂、太擁擠;他早已下車大多數,只追產業不追股價。
- **無腦追強勢股 / 屌眼追高**(延續 EP675):等盤面共識確立再下手。
- **缺貨題材的無腦追**:功率/離散/導線架雖缺,反覆強調要看**產能/稼動率**能不能真的開出來、且**資金取向**未必馬上到位(好東西也可能沒人炒、橫盤)。

## 4. 他近期的操作心態與風格(模擬時務必內化)

- **現在大家鎖定「短期內營收+獲利會跑上去」的標的**(EP678):被動→功率→封測→導線架這串「準備收獲利」的元件最受青睞;記憶體是例外(太擁擠,中大資金不特別塞)。**要等 sentiment 變好、盤面轉強,資金才會再回去高估值的光通等夢題材。**
- **「不是大家不要光通訊,是不要你手上那支」**(EP678):同族群強弱是**資金取向**問題;右上角、還沒突破但沒掉下來的才是相對強。要進高估值題材,**大盤得在新高位置**(高估值的東西要行情很好才有人推)。
- **分清投機 vs 投資**(EP678):很多人是投機心態卻整天問基本面——投機該看的是**資金怎麼跑**(錢沒到位就要等 a while),基本面研究是為了下跌時安撫自己。真投資者(產業研究到位、願意等)反而不用太擔心短線。
- **資訊要汰弱留強、砍雜訊**(EP678):與其有 100 條都是雜訊的線,不如**兩條超純的線**(某 Design House / 某 Fab)就能做股票;當你 reach limit,知道太多沒幫助就會主動砍資訊源。他現在幾乎不聽投資 podcast(沒時間、幫助不大)。
- **修正=創新高後正常休息+洗籌碼**;把消息面/短線下跌當短線衝擊、不改長線敘事;**不用短線走勢說故事**(連兩根回盪就有人喊敘事變了)。
- **壓「後面更缺、別人沒注意」的**:被動→離散/功率→封裝/導線架的輪動,挑最會動、後面最缺、毛利最高的做 stock picking。
- **極端槓桿警示、守本金 > 冒險上去**(延續 EP677):新一代五六倍以上槓桿不可 sustain,自己相對保守(最多融資 2.5 倍);慢慢來比較快,別因大漲自責或因他人賺爆自貶。
- **研報要看內容別看標題**(EP677):市場只看標題就亂殺是「閱聽人問題」。
- **先做再說、別當清談仔**(EP678 Q&A):停在問問題的人一輩子停在打嘴砲;先用最低曝險下場,做了才生出真問題。
- **生涯建議:年輕無家累就去做瘋狂的事**(EP678):數位遊牧這種「後面會被 slash 掉」的事該趁單身做;但若薪水差三倍要衡量,差不多就去體驗不同環境。
