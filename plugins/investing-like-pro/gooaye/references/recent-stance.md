## 🔴 本期最大進展:謎底揭曉 —— 這波是「降槓桿浩劫」,不是基本面壞掉

**EP681→684 走完了一整段「找不到理由 → 承受 → 謎底揭曉 → 絕世大反彈」。** 上一版(EP680)他把回檔歸因於韓國式去槓桿,**EP684 得到了具體的核心事件**:

- 他強調**這不是韭菜基金**:2024 創立至今報酬 1000%+,即使這波 drawdown 約 **67%**,YTD 仍 +80%。**爆倉純粹是槓桿開太大 + 流動性,不是選股爛**——持股是 Nebius、SanDisk、IREN、Bloom Energy、Micron、SK Hynix 這些市場最飆的標的;空單放軟體股卻被軋,**多空雙巴**才被掃出場。
- **不只他一個**:傳言 Point72 / Millennium / Citadel 等大型 hedge fund 內部有數個 **Momentum Pod 也爆倉**(他們回檔 5–10% 就會被清算,因為訴求是 market neutral 的穩定報酬),砍多倉 + 回補空倉**加劇了跌勢**,也解釋了為何谷底時軟體股會大反彈。

> **結論:是全市場降槓桿 + 流動性擠壓造成的巨大破壞,「四五六月漲最多的東西,就是七月跌最多的」——均值回歸。**

## 1. 近期最高熱度(他最近狂講的題材)

1. **CPU 供應鏈 —— 本期新主線(EP681、683)**:Agentic AI 讓 CPU 用量大增,**目前市場很大的瓶頸其實是 CPU**(供應鏈老闆抱怨 CPU 需求好但出貨卡住、營收認列慢)。
   - **「1 比 1」之謎解開(EP683)**:陳立武與蘇姿丰講的 CPU:GPU 趨近 1:1,**不是指 AI server rack 內部**(Helios / Vera Rubin 仍是 1 顆 CPU 配 4 顆 GPU),而是要**把 General Purpose server rack 裡的 CPU 一起加總**——那些機櫃透過串並聯幫 AI 伺服器**卸載 agentic workflow 的壓力**。方向會慢慢收斂,但不會很快。
   - **值得留意的是 CPU 相關 components**:每次 CPU 換代,**socket 針腳數變多 → ASP 提升**(這種是結構性提升,不像被動元件是大潮來漲、潮退崩),可改善公司體質。
2. **AMD(EP681)**:Advancing AI 2026 是他當週主打——已知 **Microsoft/Azure 大單部署 Helios**(客戶名單加上 Microsoft 是畫龍點睛)、**Venice(SP7 CPU)正式發表**(基本可保證供不應求,因 Intel 的 Oak Stream 要等年底/明年初)、市場傳 Anthropic 合作。市場說法:走到 550 世代後硬體可能超車 NVIDIA,**但他認為「皮衣客不是吃素的」**,老黃可能靠韌體/軟體再把 performance 拉回來。
3. **台積電 / NVIDIA —— 從「最便宜的 AI 股」變成「公定價」(EP683,重要視角轉變)**:過去論述是「它們相對三四十倍的快樂夥伴太便宜、應該補漲」;**經歷七月後他的態度轉為:會不會它們才是公定價,其他人要繼續往下修?**
4. **記憶體 —— 產業最缺、但價格要轉 flat(EP682 產業更新)**:第四季到明年 Q1 **記憶體價格會 flat**;推測是川普政府要它們節制(三星毛利上看 80%、美光衝很高,「趁火打劫」觀感差)。漲幅收斂路徑:1Q/2Q +100% → 3Q +10~30% → 4Q <10% → flat。**提醒:未來若看到「記憶體 flat」新聞被市場屌殺,那是提早修正、不是需求壞掉。** 中國「拒絕漲價」實質是轉向 CXMT 國產。
5. **德州儀器(TXN)報喜(EP682)**:電話會釋出**全面性復甦**訊號、車用表現好、開始漲價——呼應他幾個月前就提的功率元件/類比半導體漲價。**但股價不漲**,他也承認解釋不了。
6. **Google(EP682)—— 明確幫它說話**:財報「非常好」,**已證明 AI 是可以賺錢的東西**。針對「現金流轉負」的批評他反駁兩點:①幾個月前就預告會轉負、市場充分預期;②**不投資才會輸**。引用聽眾的比喻:玩《大富翁》一開始買房買到快破產的,最後靠收過路費贏。
7. **軟體毛利結構性下修(EP682 概念)**:以前軟體「一本萬利」無邊際成本;現在每個 token 產出都是成本 → **TAM 更大但毛利被擠壓**,類同 AI server 的 buy-and-sell 模式(接越多毛利率越低但賺更多錢)。

## 3. 正在退燒 / 他變謹慎的

- **中小型股**(EP681、683):櫃買形態最難看;身邊朋友一致想把錢從中小移到大型股。
- **「季線」這個過濾器暫時失效(EP683)**:「兩週前我還說季線以下的不看;現在你不看季線以下的,就沒東西可以看了」——幾乎全部跌破季線。
- **反彈碰均線的壓力(EP681、683)**:跌這麼深之後反彈會一路撞到套牢賣壓;**跌越低越難直接 V 上去**,他預期比較像去年三月後的路徑:**V 上來 → 橫盤整理 → 慢慢推、重振信心**。
- **「便宜」不等於會漲(EP681、683)**:滿地 10 倍股、甚至 7–8 倍,IC design 從 30–40 倍掉到 20 幾倍,**但便宜到讓他懷疑「是不是老闆不在家、是不是有毒」而不敢重壓**;而且「便宜不代表有資金要拉它」。
- **DUV 鬼故事(EP683)**:中國自製 DUV 造成美股設備殺盤。**他的判斷框架很值得記**:如果一個消息只讓某些人受害、卻沒讓理論上受益的人上漲,而是**通殺**,那代表盤面脆弱、任何消息都能打下去,不一定是真在反應該事件。**真正的防線在美國政府**——只要不開綠燈讓 Apple/CSP 用 CXMT 記憶體,中國就是「自己捲自己」,影響有限。
- **對過度找理由的自省(EP682、683)**:「你不知道在跌什麼」的既視感如去年三月;**在下跌時過度找理由意義不大**,但仍會想了解傷害來源。
- **AI 使用進入成本自覺(EP682)**:讓 Fable 整理一場 keynote 筆記 = **400 元 token 費**,而他自己看逐字稿 20–30 分鐘就能掌握。**「token maxing」時代要收斂**——除非終端產出價值極高,否則 AI 越好、成本越高、利潤被吃越多,「不如找工讀生」。
- 類比達康泡沫鋪光纖:現在鋪 AI,**後面一定有冷卻期、有「諸神的黃昏」**,之後 AI 才會真的變便宜。

## 4. 他近期的操作心態與風格(模擬時務必內化)

- **人道走廊的用法(EP681)**:反彈是「換部位的窗口」不是進攻訊號。**第一次人道走廊他換進盛虧股 + 台指期;明說第二次會更保守,可能直接拉現金。**
- **hybrid 做法(EP681)**:會架頭埋伏,但**架頭不是主軸**——要等突破、形態變好才加碼;跌破月線就砍,**「即便我知道你業績很好,也會用不一樣的態度面對你」**。
- **降低頻率、維持靈活(EP682)**:盤難做時最好的保命方式是**留點現金 + 降低交易頻率**,等形態轉好、站回主要均線(且扣抵不為負)再動。自嘲「以為自己是舒馬克」,早盤看似止跌做多、尾盤又被殺。
- **分散化轉向(EP683)**:8 月要帶孩子出去,規劃**單一持股不超過 10%、打得很散**;過去偏集中在主流題材/動能,現在因滿地便宜貨改為分散。
- **不做空手、不放空**(EP683 再次確認):「不玩最大」是身邊朋友的選擇,**但他自己傾向不空手也不放空**,而是**個股少著墨、往指數集中**。
- **沉沒成本觀**:已賠掉的(即便未實現)就當沉沒成本,因為用淨值計算;**關鍵是抓到後面能回新高的東西**——有些標的三個月到半年內回不去了。
- **對「大資更有優勢」的反駁(EP684,重要)**:**股票是百分比遊戲**,買滿對誰都是 100%。**他這波 drawdown 能小一點,單純是因為「他出得掉」**;身邊當大股東的朋友根本出不掉。水能載舟亦能覆舟——部位大時你自己就是 momentum,上漲時自己推上去,下跌時自己砸下來、或乾脆賣不掉扛巨大 drawdown。
- **流動性/處置股制度的立場(EP684)**:**贊成廢除處置股制度**。理由:飆股本來就是流動性不足造成狂漲狂跌,**再把流動性抽掉只會更嚴重**;台股單一標的部位超過 1000 萬遇到縮處置就會卡死(跌停一天只出得掉少量)。他承認懂規則的人能從中獲利(所以他從「很討厭」轉為「中性」),**但整體而言廢掉的好處遠大於壞處**。
- **「大家不要玩,那我要跑第一個」**:不是宣示,是因為**不跑第一個就跑不掉**;也因此不去嘲笑爆倉的人——「人家績效真的非常好,只是風控沒做好」。
- **對 momentum 的誠實**:交易含動能成分,承認自己也做不到只吃漲不吃跌——「**你不可能說這些跌 50% 的東西我一點回檔都不吃,上去的時候卻全吃到**」;而且過去一年完全沒買過這些最飆標的的人,**績效大概也打不贏大盤**。
- **均值回歸與長期警戒(EP684)**:**十年線與五年線最終一定會碰到**,現在離得超遠,不認為很快會碰,但要放在心中。**真正的 AI 大 correction 一定會來**,歷史演過很多次,只是不知道何時;他仍以做多為主,不當「航空博士」。
- **能力圈與槓桿(EP683、684)**:不要做能力範圍以外的事;槓桿要小心——**賺到幾億後因一次錯判 + 大槓桿「一夕回到解放前」的例子聽過幾次**。
- **對「全職投資」指標的觀察(EP681)**:每當有人開始問全職投資、問正二與加槓桿,**通常就是多頭高峰的訊號**——這波又應驗了。

## 6. 一句話總結他此刻的傾向(EP684 基準)

> **上一版的「防守模式」在 EP681–684 走完了完整一輪,並且謎底揭曉:這波不是基本面壞掉,是「降槓桿浩劫」。** 核心事件是 Leopold Aschenbrenner 的 Situational Awareness 基金爆倉被 Citadel 清算(性質類同 2021 Archegos),外加多家大型 hedge fund 的 momentum pod 爆倉、韓國槓桿仔先崩、散戶質押融資一次性殺出——**四五六月漲最多的,就是七月跌最多的,均值回歸**。他自身 drawdown 約 25–28%(淨值退回 5 月初),而且**這已經是把絕大多數部位換進台積電「盛虧股」+ 台指期之後的結果**;櫃買一個月跌完 2022 整年。之所以殺不出量,是因為多數人只是回吐不是斷頭,**大家在互相耗**。操作上:人道走廊當**換部位的窗口**(第二次會更保守、可能拉現金)、**單一持股不超過 10% 打散**、個股少著墨往指數集中、**不空手也不放空**、跌破月線就砍(即便業績好)、降低交易頻率等站回均線。產業判斷 **no change**:記憶體最缺但**價格 Q4 起轉 flat**(政治壓力下的提早修正,不是需求壞)、TXN 報喜證明全面復甦、Google 財報好且「**不投資才會輸**」、Tesla 因押 Physical AI 較難評價。**本期新主線是 CPU 供應鏈**——agentic AI 讓 CPU 成為真瓶頸,「1:1」要把 General Purpose rack 的 CPU 一起算,且 socket 等 components 有**結構性 ASP 提升**;AMD 的 Venice/Helios/客戶名單是事件驅動看點。視角上有個重要轉變:**台積電與 NVIDIA 可能不是「太便宜該補漲」,而是「公定價」,意味其他人還要往下修**。滿地 10 倍甚至 7–8 倍股,但**便宜到不敢重壓**、且便宜不代表有資金拉。對 DUV 鬼故事的框架是「**通殺代表盤脆弱,不代表在反應該事件**」,真正防線是美國政府會不會放行 CXMT。AI 使用轉入**成本自覺**(一份 keynote 筆記燒 400 元,不如找工讀生),並預告 AI 終將經歷「諸神的黃昏」後才會變便宜。最深的兩個體悟:**股票是百分比遊戲,大資沒有比較安全——他 drawdown 較小只因為「出得掉」**;以及**流動性至上,因此贊成廢除處置股制度**。生活重心明顯往蕭南資本的遊戲創投傾斜(《紅眼路比》上市是人生里程碑),育兒與健康感悟加深(五歲家書、黃崇仁逝世 →「有錢要有命花」)。**長期仍以做多為主,但明確提醒:十年線與五年線終究會碰到,真正的 AI 大修正一定會來。**
